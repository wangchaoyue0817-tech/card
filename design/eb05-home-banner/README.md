# EB05 首页 Banner

尺寸 678 × 214 px，圆角 26 px；另附 1356 × 428 高清版，圆角按比例放大为 52 px。

标题：海贼EB05卡牌免费抽卡活动。按钮：立即参与。

提取素材中的草帽骷髅、珐琅徽章、罗盘和航海绳索，配蓝紫卡牌叠层、丝带与少量金色彩屑。标题、按钮、尺寸与圆角采用确定性排版；不添加英文眉题、日期、赠券数量或中奖承诺。设计图不是实际 EB05 卡面或包装图。

## 文件

- `eb05-home-banner-678x214.png`：指定尺寸成品，四角透明。
- `eb05-home-banner-1356x428.png`：2 倍尺寸成品，四角透明。
- `art-background.png`：内置 image_gen 生成的无字原始素材。
- `generation-prompt.txt`：完整生成提示词及输入来源。
- `banner-spec.json`：文案与排版参数。
- `export-banner.mjs`：确定性排版导出脚本；需要 `@napi-rs/canvas`，可用 `BANNER_CANVAS_MODULE` 指定模块路径。
- `export-manifest.json`：尺寸、文字边界及 SHA-256 校验。

本次仅交付设计素材，未替换首页、未部署线上。正式接入时，应保留可访问的活动名称及真实按钮/链接，不能让图片里的按钮文字成为唯一的可访问名称。
