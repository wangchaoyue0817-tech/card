# 图灵鉴 X · 海贼 EB05 第二期 Demo

本工程是独立的新线上版本，不覆盖原统一体验站点。仅前端演示，无后台接入。

需求对照见 [海贼 EB05 第二期活动需求文档（修订版）](docs/eb05-phase2-delta-prd.md)，包含一期对比、业务流程、复用范围与验收条件，以用户最新确认的双入口新人礼及沿用规则为准。

## 运行

Node.js 22 或更高版本，安装依赖后：

```sh
npm install
npm test
npm run build
python3 -m http.server 8818 --directory dist
```

打开 `http://localhost:8818/`。站内页面使用 hash 路由，不跳往其他活动域名。

## 已接入

- `/#home`：保留原统一版本首页及技能入口。
- `/#skin`：保留 AI 肌肤检测；皮肤管理和商品订单路由同时保留。
- `/#expert`：复用用户提供 Demo 的专家鉴定及双11活动。
- `/#card`：复用卡牌鉴定页面，首次直达为符合资格的新用户发放第二期新人券；AI 结果联动第二期获券与奖池门槛。
- `/#lottery`：活动选择，保留双11、第一期卡牌两个入口，新增海贼 EB05 第二期。
- `/#prizes`：保留原 Demo 奖品汇总，追加第二期奖品摘要入口。
- `/#card-eb05`：第二期普通券、新人券、单抽/五连抽、获券记录、三种券状态、奖池与规则。
- `/#card-eb05-prizes`：第二期实物奖品、地址、专家鉴定券与抽奖结果。

第二期已支持主要流程的本地演示，默认时间为 2026-10-30 12:00，页面持续标注“前端演示”。不接入真实注册、鉴定、支付、微信转发、订单、库存、寄送或反作弊服务。记录保存在当前浏览器，不实现后台隔离。

当前 Demo 与最新确认需求的差距：新人礼尚未接入“首页传图识别卡牌后出现选款入口”的触发。需求保留两个入口且不重复领取；本次仅更新文档，不能据此认定双入口功能已经完成。

## 已确认规则

- 活动时间：2026-10-30 00:00 至 2026-11-05 23:59（北京时间）。
- 新人：活动内新注册用户进入鉴卡牌二级页，或首页传图识别卡牌后出现选款入口，自动获得 5 张新人专属券；两入口共用一次领取资格，不重复领取、不重置有效期。24 小时有效且不晚于活动结束，只能整组五连抽，1% 实物 / 99% 专家鉴定券。该业务规则沿用，当前实现差距见上文。
- 普通券：AI 卡牌成功出结果、专家卡牌支付或用券成功，各送 1 张；每天共 10 张。普通券活动结束失效，支持单抽、五连抽，8% 实物 / 92% 专家鉴定券。
- 结果累计沿用：卡牌 AI 和人工成功出结果计入进度；专家支付仅发券，不计入进度，人工出结果不再重复发券。统计范围及跨阶段去重沿用既有口径。本期新增按 70／100 单开放奖品；进度次日重算，奖品库存不重置。
- 固定实物权重：乔巴杂志 20%（70 单开放、3 份）；精选套装 15%（100 单开放、1 份）；EB05 单包 50%（全程开放、40 份）；EB05 整盒 15%（100 单开放、2 份）。
- 命中未投放或已抽空的品类时，用 **1 张专家鉴定券** 补位；不返还抽奖券、不重抽、不重新分配其他实物权重。专家券有效 7 天，不随活动结束提前作废。
- 满额分享：每天仅第 10 张鉴定获券弹窗可领 5 张；关闭、离开或刷新后当天不可补领，不占鉴定额度。
- 邀请：转发小程序，没有邀请链接。转发本身不发券；新用户完成注册后，最后邀请人获得 5 张，同一新用户只计一次。
- 收货：活动结束前必须填写地址，未填视为放弃；结束后已填地址也不能修改。活动结束后 7 个工作日内寄出。

## 演示方式

1. 从首页进入鉴卡牌，体验新人礼包；使用演示卡牌、选择款式、完成 AI 鉴定，可看到 +1 张券与奖池进度同步增加。
2. 在第二期页右上角打开“演示设置”，可切换 69/70/99/100 单、售罄、次日、券过期、实物中奖、活动结束等场景。切换场景只替换本期模拟记录。
3. 设置中的“专家卡牌支付成功”仅增加获券；“人工卡牌出结果”仅增加门槛；“模拟使用 1 张鉴定券”消费本期有效券并按规则获券。
4. 原专家页面保持免费提交。卡牌报告新增明确标注的“第二期演示：结算与发券”按钮，只有模拟支付成功才发第二期券；免费提交不会被当成支付。
5. 专家券面“去使用”按之前要求保留入口提示，暂不跳转真实服务。用券闭环通过演示设置验证。
6. 地址请使用“填入演示地址”，不要输入真实个人信息；仅本机保存，不用于配送。
